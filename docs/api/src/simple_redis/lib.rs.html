10//! # simple_redis
11//!
12//! Simple and resilient [redis](https://redis.io/) client based on [redis-rs](https://crates.io/crates/redis) with
13//! internal connection and subscription handling.
14//!
15//! This library provides a very basic, simple API for the most common redis operations.<br>
16//! While not as comprehensive or flexiable as [redis-rs](https://crates.io/crates/redis),
17//! it does provide a simpler api for most common use cases and operations as well as automatic and resilient internal
18//! connection and subscription (pubsub) handling.<br>
19//! In addition, the entire API is accessible via redis client and there is no need to manage connection or pubsub
20//! instances in parallel.<br>
21//!
22//! ## Connection Resiliency
23//!
24//! Connection resiliency is managed by verifying the internally managed connection before every operation against the
25//! redis server.<br>
26//! In case of any connection issue, a new connection will be allocated to ensure the operation is invoked on a valid
27//! connection only.<br>
28//! However, this comes at a small performance cost of PING operation to the redis server.<br>
29//!
30//! ## Subscription Resiliency
31//!
32//! Subscription resiliency is ensured by recreating the internal pubsub and issuing new subscription requests
33//! automatically in case of any error while fetching a message from the subscribed channels.
34//!
35//! # Examples
36//!
37//! ## Initialization and Simple Operations
38//!
39//! ```
40//! fn main() {
41//!     match simple_redis::create("redis://127.0.0.1:6379/") {
42//!         Ok(mut client) =>  {
43//!             println!("Created Redis Client");
44//!
45//!             match client.set("my_key", "my_value") {
46//!                 Err(error) => println!("Unable to set value in Redis: {}", error),
47//!                 _ => println!("Value set in Redis")
48//!             };
49//!
50//!             match client.get_string("my_key") {
51//!                 Ok(value) => println!("Read value from Redis: {}", value),
52//!                 Err(error) => println!("Unable to get value from Redis: {}", error)
53//!             };
54//!
55//!             match client.set("my_numeric_key", 255.5) {
56//!                 Err(error) => println!("Unable to set value in Redis: {}", error),
57//!                 _ => println!("Value set in Redis")
58//!             };
59//!
60//!             match client.get::<f32>("my_numeric_key") {
61//!                 Ok(value) => println!("Read value from Redis: {}", value),
62//!                 Err(error) => println!("Unable to get value from Redis: {}", error)
63//!             };
64//!
65//!             match client.hgetall("my_map") {
66//!                 Ok(map) => {
67//!                     match map.get("my_field") {
68//!                         Some(value) => println!("Got field value from map: {}", value),
69//!                         None => println!("Map field is emtpy"),
70//!                     }
71//!                 },
72//!                 Err(error) => println!("Unable to read map from Redis: {}", error),
73//!             };
74//!
75//!             /// run some command that is not built in the library
76//!             match client.run_command::<String>("ECHO", vec!["testing"]) {
77//!                 Ok(value) => assert_eq!(value, "testing"),
78//!                 _ => panic!("test error"),
79//!             };
80//!
81//!             /// publish messages
82//!             let result = client.publish("news_channel", "test message");
83//!             assert!(result.is_ok());
84//!         },
85//!         Err(error) => println!("Unable to create Redis client: {}", error)
86//!     }
87//! }
88//! ```
89//!
90//! ## Subscription Flow
91//!
92//! ```rust,no_run
93//! use simple_redis::{Interrupts, Message};
94//!
95//! fn main() {
96//!     match simple_redis::create("redis://127.0.0.1:6379/") {
97//!         Ok(mut client) =>  {
98//!             println!("Created Redis Client");
99//!
100//!             let mut result = client.subscribe("important_notifications");
101//!             assert!(result.is_ok());
102//!             result = client.psubscribe("*_notifications");
103//!             assert!(result.is_ok());
104//!
105//!             // fetch messages from all subscriptions
106//!             client.fetch_messages(
107//!                 &mut |message: Message| -> bool {
108//!                     let payload : String = message.get_payload().unwrap();
109//!                     println!("Got message: {}", payload);
110//!
111//!                     // continue fetching
112//!                     false
113//!                 },
114//!                 &mut || -> Interrupts { Interrupts::new() },
115//!             ).unwrap();
116//!         },
117//!         Err(error) => println!("Unable to create Redis client: {}", error)
118//!     }
119//! }
120//! ```
121//!
122//! ## Closing Connection
123//!
124//! ```rust
125//! fn main() {
126//!     match simple_redis::create("redis://127.0.0.1:6379/") {
127//!         Ok(mut client) =>  {
128//!             println!("Created Redis Client");
129//!
130//!             match client.set("my_key", "my_value") {
131//!                 Err(error) => println!("Unable to set value in Redis: {}", error),
132//!                 _ => println!("Value set in Redis")
133//!             };
134//!
135//!             match client.quit() {
136//!                 Err(error) => println!("Error: {}", error),
137//!                 _ => println!("Connection Closed.")
138//!             }
139//!         },
140//!         Err(error) => println!("Unable to create Redis client: {}", error)
141//!     }
142//! }
143//! ```
144//!
145//! # Installation
146//! In order to use this library, just add it as a dependency:
147//!
148//! ```ini
149//! [dependencies]
150//! simple_redis = "*"
151//! ```

186/// Constructs a new redis client.<br>
187/// The redis connection string must be in the following format: `redis://[:<passwd>@]<hostname>[:port][/<db>]`
188///
189/// # Arguments
190///
191/// * `connection_string` - The connection string in the format of: `redis://[:<passwd>@]<hostname>[:port][/<db>]`
192///
193/// # Example
194///
195/// ```
196/// extern crate simple_redis;
197///
198/// fn main() {
199///     match simple_redis::create("redis://127.0.0.1:6379/") {
200///         Ok(client) => println!("Created Redis Client"),
201///         Err(error) => println!("Unable to create Redis client: {}", error)
202///     }
203/// }
204/// ```
